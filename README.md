# 💰 Student Budget Buddy

A simple and student-friendly website to manage monthly budgets and track daily expenses.

## 📌 About the Project

Student Budget Buddy helps students keep track of their spending, manage their monthly allowance, and understand how much money they have left.

The project is built using HTML, CSS, and JavaScript.

## ✨ Features

* 💵 View your monthly budget
* 📊 Track total spending and remaining money
* 🎯 Update your monthly budget
* ➕ Add new expenses
* 🏷️ Categorize expenses such as Food, Travel, Study, Shopping, and Entertainment
* 📈 View budget progress with a progress bar
* 🧾 View recent expenses

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout
* **JavaScript** — Budget calculations and expense tracking

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start managing your budget!
